ESKM Certificates Update on HPE iLO

  • Input Field: Enter the iLO names (FQDN) or IP addresses, separated by commas.
  • File Upload: Upload a text file containing iLO names (FQDN) or IP addresses, each on a new line.
  • Notes:
    • Receive instant notifications on the success of your file upload
    • The list from your uploaded file will be deplay before you can click patch eskm button
    • If the input box has an entry, it will take priority over the file upload.
    • To clear or restart click on ESKM menu again on left
    • Current Limit is 100 host/server
    • you can provide ilo username and password or it will use default BMI user creds

you can leave ilo user and password empty to use default BMI user creds
